# Jenkins et al. — notebook porting project

This repo is mid-way through porting `notebooks/`/`scripts/` (read-only,
frozen at commit `2d19f3a`) into a `src/jenkins_et_al/` package, using the
`/golden-refactor` skill, one notebook/script at a time, named by the user.

**Read `PORTING_PLAN.md` first** — it's the up-to-date status table, agreed
porting order, decisions already made, and per-notebook flags. Update it as
work progresses.
